# WakaLoka

*Explore Wakatobi, Support Local*

WakaLoka adalah website wisata Wakatobi yang memperkenalkan destinasi lokal dan mendukung UMKM setempat. Proyek ini saat ini berupa website statis dengan halaman Beranda, Profil, Galeri, dan Data.

## Fitur

- Menampilkan informasi destinasi wisata dan Wakatobi.
- Menampilkan galeri dan data terkait wisata.
- Memperkenalkan produk lokal dan UMKM.

## Menjalankan Website

Buka [`frontend-sementara/index.html`](./frontend-sementara/index.html) di browser.
