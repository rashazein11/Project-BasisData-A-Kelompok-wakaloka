Alur halaman aplikasi

  1. Halaman Awal: tombol Start memulai aplikasi.
  2. Login: masuk dengan email atau nomor telepon dan password.
  3. Home: 2 rekomendasi wisata, tombol View, Explore, dan Profile.
  4. Explore: 6 pilihan wisata dengan tombol View.
  1. Profil wisata: detail destinasi dan produk UMKM, tombol Check Out.
  2. Check Out: konfirmasi pesanan, tombol Order Now.
  3. E-Tiket: tiket digital dengan ID tiket untuk petugas loket.
  4. Terima kasih: tombol Kembali ke Beranda.
