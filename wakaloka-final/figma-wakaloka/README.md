# Desain Figma WakaLoka

Dokumentasi desain antarmuka WakaLoka, website dan aplikasi mobile untuk menjelajahi destinasi wisata Wakatobi, memesan tiket, dan mendukung produk UMKM lokal.

## Isi desain

File gambar di folder ini merupakan dokumentasi layar dan state desain:

| File | Deskripsi |
| --- | --- |
| `01 Start.png` | Halaman pembuka |
| `02 Login.png` | Form masuk wisatawan |
| `03 Daftar.png` | Form pendaftaran akun |
| `04 Beranda.png` | Beranda dan rekomendasi destinasi |
| `05 Menu mobile terbuka.png` | Navigasi menu pada tampilan mobile |
| `06 Jelajah.png` | Daftar dan pencarian destinasi |
| `07 Detail Tomia.png` – `12 Detail Goa Kontamale.png` | Detail enam destinasi wisata |
| `13 Checkout.png` | Ringkasan dan proses pemesanan |
| `14 E-tiket.png` | Contoh tampilan e-tiket |
| `15 Terima kasih.png` | Konfirmasi setelah pemesanan |
| `16 Riwayat.png` | Riwayat pesanan |
| `17 Akun pengguna.png` | Informasi akun wisatawan |
| `18 Validasi petugas.png` | Pencarian dan validasi tiket oleh petugas |
| `19 Galeri.png` | Galeri destinasi |
| `20 Data tarif.png` | Informasi tarif dan ringkasan pesanan |
| `21 State penting.png` | Contoh state validasi, error, dan pemrosesan |
| `22 Panduan implementasi.png` | Panduan implementasi desain |
| `Asset.png` | Aset navigasi bawah |

Desain mencakup tampilan desktop dan mobile. Contoh pemesanan dan validasi pada prototype bersifat simulasi.
